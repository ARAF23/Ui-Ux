## Overview

A UI/UX design coursework project featuring an interactive pizza ordering prototype developed using Figma.

The repository documents interface design exercises, prototyping, and the final design project.

## Design Objectives

- User-friendly interface
- Intuitive navigation
- Consistent visual design
- Interactive user experience
- Simplified ordering experience

## Tools and Concepts

- Figma
- UI/UX Design
- Wireframing
- Interactive Prototyping
- Visual Design
- User Interface Design
