# FireSlice Pizza

FireSlice Pizza is a mobile UI/UX design project for COMP 1011. The interactive Figma prototype shows how customers can find a nearby outlet, customize a pizza, and place an order for pickup or delivery.

## Final prototype

**[Open the final FireSlice Pizza prototype in Figma](https://www.figma.com/proto/A0q81toIIRfVvRXj5uWxyO/Wasi_-Pizza_final?node-id=7-1286&t=xtwXXUH6o11rskP4-1)**

To try the main flow, choose an outlet, select a pizza, customize it, and follow the checkout steps.

## What you can explore

- Browse outlets and pizza categories, filter the menu, and save favourites to a wishlist.
- Customize pizza size, crust, and toppings, then review your items in the cart.
- Choose pickup or delivery, schedule an order, apply a promo code, or send an order as a gift.
- Track or cancel an active order, review past orders, and view or submit ratings.

## Design process

The project began with interviews and surveys about how people order pizza. The research showed that customers value quick ordering, easy customization, and reliable order updates. Usability testing helped refine the checkout flow, clarify the ASAP and scheduled ordering options, and improve cancellation feedback and order history.
